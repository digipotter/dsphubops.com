# dsphubops.com

Static site for DSP Hub Ops LLC. Plain HTML, one stylesheet (`assets/css/site.css`) and one small script (`assets/js/site.js`).

## Editing pages

The HTML pages are generated by `_src/build.py` (Python 3, no packages needed). Edit the sources, then rebuild:

```bash
python3 _src/build.py
```

| To change | Edit |
|---|---|
| Header, footer, navigation, phone | `_src/build.py` (top of the file) |
| Home, Services, About, Contact, Privacy, Terms, 404 | `_src/pages/*.html` |
| The seven service pages, the three client pages, the FAQ page, careers roles | `_src/content.py` |
| Resource articles | `_src/resources/*.html` (one file per article; the comment block at the top holds its title, summary and category) |

The build also rewrites `sitemap.xml`. Don't edit the generated `index.html` files directly; the next build overwrites them.

## Preview locally

```bash
python3 -m http.server 4192
```

Then open http://localhost:4192.

### Forms

Both forms (pricing on the Contact page, and Careers) post to [Formspree](https://formspree.io). They are defined in `_src/formspree.json`, which also sets the inbox they email, and deployed with the Formspree CLI using the project's deploy key:

```bash
cd _src
FORMSPREE_DEPLOY_KEY="$(cat ~/.dsphubops-formspree-key)" npx @formspree/cli@0.9.6 deploy
```

Keep the deploy key out of the repository. The site finds each form at `https://formspree.io/p/<project id>/f/<form key>`, built from `FORMSPREE_PROJECT` at the top of `_src/build.py`. A new recipient address gets one verification email from Formspree before submissions reach it.
