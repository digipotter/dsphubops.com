# dsphubops.com

Static site for DSP Hub Ops LLC. Plain HTML, one stylesheet (`assets/css/site.css`) and one small script (`assets/js/site.js`).

## Editing pages

The HTML pages are generated by `_src/build.py` (Python 3, no packages needed). Edit the sources, then rebuild:

```bash
python3 _src/build.py
```

| To change | Edit |
|---|---|
| Header, footer, navigation, phone, address | `_src/build.py` (top of the file) |
| Home, Services, About, Contact, Privacy, Terms, 404 | `_src/pages/*.html` |
| The seven service pages, the three client pages, the FAQ page, careers roles | `_src/content.py` |
| Resource articles | `_src/resources/*.html` (one file per article; the comment block at the top holds its title, summary and category) |

The build also rewrites `sitemap.xml`. Don't edit the generated `index.html` files directly; the next build overwrites them.

## Preview locally

```bash
python3 -m http.server 4192
```

Then open http://localhost:4192.

## Color options

The owners are comparing palettes. `/colors/` (not linked from the site, hidden from search engines) shows each option, and any page opened with `?theme=<name>` shows the whole site in that palette with a switcher at the bottom. Options: `current`, `signal`, `harbor`, `cobalt`, `plum`, `fleet`. Palettes live at the end of `assets/css/site.css`; the list also appears in `THEMES` in `_src/build.py` and in `assets/js/site.js`.

Once a palette is chosen, copy its values into the `:root` block at the top of `site.css`, then remove the colour options section, the `/colors/` page and the switcher.

### Contact form

The form posts to [FormSubmit](https://formsubmit.co), which emails each submission.

1. The first submission to a new address sends an activation email to that inbox. Click the link once.
2. After activation, FormSubmit offers a random alias for the address. Swap it into the form `action` so the real email isn't visible in the page source.
3. To change inboxes later, edit the address in the form `action` and activate again.

## Deploy on GitHub Pages

The repository is `digipotter/dsphubops.com`, published from the `main` branch, root folder. All links are relative, so the site works on the temporary `digipotter.github.io/dsphubops.com/` address and on the real domain.

To move to dsphubops.com:

1. At the domain registrar, add:
   - `A` records for `dsphubops.com` pointing to `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`
   - a `CNAME` record for `www` pointing to `digipotter.github.io`
2. Add a file named `CNAME` at the repository root containing `dsphubops.com`, or type the domain under Settings > Pages > Custom domain.
3. Tick "Enforce HTTPS" once the certificate is issued.
